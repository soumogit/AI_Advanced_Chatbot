## 📌 Overview

**HealthChat** is a next-generation AI-powered healthcare assistant designed to guide users from **symptom analysis to hospital appointments**—all through an intuitive chat-based interface. Built using modern full-stack technologies and integrated with Google’s **Gemini API**, it bridges the gap between patients and healthcare providers through real-time triage, hospital management, emergency queuing, and vital tracking.

---

## ✨ Features

- 🤖 **AI Symptom Analysis** powered by Gemini API
- 🏥 **Hospital Finder** with location-based filtering
- 📅 **Appointment Booking System** (reschedule & cancel supported)
- 🆘 **Emergency Queue Handling** for critical conditions
- 📋 **Prescription Drafting Support** for doctors
- 📈 **Health Metrics Dashboard** (Heart Rate, Sleep, BP, Steps tracking)
- 🌐 **Responsive & Accessible UI** (WCAG compliant)
- 🔒 **Secure, Scalable Full-Stack Architecture**
